# JobPilot - Job Application Tracker

JobPilot is a React-based web application designed to help
job seekers manage their job applications, interviews, and offers
from one place.

## Features

- User login with demo authentication
- Dashboard with application statistics
- Add, edit, and delete job applications
- Search, filter, and sort applications
- Track application statuses
- Kanban board for managing application stages
- Interview calendar
- Analytics and application statistics
- View applications grouped by company
- User profile management
- Settings and data management
- Responsive design for desktop and mobile
- LocalStorage data persistence

## Pages
